# Исторический транспорт для тестов API 1

Этот fixture сохраняет прежние проверки Core/Web и транспортных сбоев.
Продуктовые маршруты и wheel Core используют ASGI и не импортируют этот
каталог. Для отдельного запуска исторических проверок установите его
`requirements.lock` с `--only-binary=:all: --require-hashes` в тестовое
окружение. Обязательные проверки работающего API 2 идут через Uvicorn.
